# PickDay

PickDay는 단체 약속의 날짜, 시간, 장소를 쉽고 예쁘게 정하기 위한 Android 앱입니다.

현재 `dev` 브랜치의 목표는 단순 화면 목업을 넘어서, 서버만 붙이면 바로 배포 가능한 수준의 Android 앱으로 끌어올리는 것입니다. 즉, 백엔드 배포 전까지 앱 안에서 전체 흐름이 로컬로 동작하고, 이후 Repository/API 계층을 통해 서버 연동을 붙일 수 있어야 합니다.

현재 UI 방향은 유지합니다. 앞으로의 핵심 작업은 새 디자인을 다시 만드는 것이 아니라, 5월 고정 달력, Activity 내부 하드코딩 문자열, 임시 더미 통계처럼 실제 서비스에서 깨지는 부분을 Repository 데이터와 계산 결과 기반 기능으로 교체하는 것입니다.

## 브랜치 전략

- `main`: MVP 스냅샷 브랜치입니다. 진행 중인 개발을 직접 머지하지 않습니다.
- `dev`: 서버 연동 직전 수준까지 끌어올리는 통합 개발 브랜치입니다.
- 기능 브랜치: 반드시 `dev`에서 분기하고, `dev`로 병합할 때는 PR을 사용합니다.

브랜치명은 아래 형식을 지킵니다.

- `feat/<feature-name>`
- `fix/<bug-or-screen-name>`
- `refactor/<scope-name>`
- `docs/<document-name>`
- `style/<screen-or-system>`
- `test/<scope-name>`
- `chore/<scope-name>`

## 커밋 규칙

커밋은 기능 단위, 구현 단위로 작게 분리합니다.

커밋 메시지는 `type: 간단한 한국어 요약` 형태로 작성합니다.

- `feat`: 새로운 사용자 기능 또는 앱 흐름
- `fix`: 버그 수정
- `refactor`: 동작 변화 없는 내부 구조 개선
- `docs`: 문서 변경
- `style`: 앱 로직 변화 없는 UI 정리
- `test`: 테스트 또는 검증 코드
- `chore`: 빌드, 설정, 유지보수 작업

예시:

- `feat: 홈 화면 정리`
- `fix: 방 목록 빈 상태 수정`
- `docs: 보고서 준비 문서 추가`

동작, 화면 흐름, 데이터 구조, 디자인 규칙이 바뀌는 PR은 관련 문서를 함께 업데이트해야 합니다.

## 코드 작성 규칙

- 코드 주석은 한국어로 작성합니다.
- 주석은 복잡한 의도, 예외 처리, 화면/도메인 규칙을 설명할 때만 사용합니다.
- 변수명, 함수명, 클래스명은 기존 Android/Java 관례를 따라 영어로 작성합니다.
- 화면에 노출되는 문구는 사용자에게 자연스러운 한국어를 우선합니다.

## 현재 개발 방향

첨부된 목업은 최종 정답이 아니라 시각 방향을 잡기 위한 참고 자료입니다. 실제 완료 기준은 목업 복제가 아니라 서비스 화면으로서 예쁘고 간결하며, 데이터가 없을 때도 거짓 정보를 보여주지 않는 일관된 사용성입니다. 부드러운 카드형 레이아웃, 정돈된 곡률, 일관된 폰트, 절제된 아이콘, 파스텔 퍼플 중심의 색감을 기준으로 합니다.

아이콘은 뒤로가기, 공유, 복사, 알림, 캘린더, 마감, 체크, 다음 이동처럼 행동이나 상태를 명확하게 보여주는 경우에만 사용합니다. 채팅 방 목록, 프로필, 참여자 아바타처럼 실제 데이터가 중심이어야 하는 영역에서는 장식용 이모지와 아이콘을 최대한 배제하고 이름, 상태, 응답률, 이니셜, 실제 이미지 중심으로 정리합니다.

PickDay 캐릭터 이미지는 장식용 이모지나 방 카테고리 아이콘이 아니라 브랜드 자산입니다. Home, Splash/Login, 방 만들기, 초대처럼 앱의 분위기를 만드는 핵심 위치에서는 기존 캐릭터 에셋을 최대한 유지합니다.

더미 데이터는 개발 중 화면 확인용 샘플입니다. 서버 또는 로컬 Repository가 빈 상태를 반환하면 Home은 기존 방, BEST 날짜, 응답률 같은 값을 임의로 만들지 않고 빈 상태와 방 만들기 CTA를 보여줘야 합니다.

달력, 참여자 수, 마감 D-day, 응답률, BEST 날짜, 시간 선호도, 참여자 상태는 고정 텍스트가 아니라 실제 방 데이터와 응답 데이터를 받아 계산해 표시해야 합니다. 추가 구현 예정 화면은 하단 내비게이션의 알림 화면과 내 정보 화면만 둡니다.
