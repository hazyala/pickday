# 수동 테스트 케이스

앱이 목업에서 서버-ready 로컬 동작으로 이동하는 동안 이 문서를 계속 업데이트합니다.

## 공통

- 앱이 crash 없이 실행됩니다.
- Splash에서 Login으로 이동합니다.
- 뒤로가기 시 저장된 데이터가 예기치 않게 사라지지 않습니다.
- 주요 UI 의미가 이모지에 의존하지 않습니다.
- 주요 화면이 현재 디자인 방향과 맞습니다.
- 현재 UI 톤은 유지되고, 하드코딩 데이터만 실제 Repository/계산 결과로 대체됩니다.

## Login / Signup

- Login 화면은 기존 시작 화면의 배경과 PickDay 브랜드 분위기를 유지합니다.
- Login 화면의 심볼 아이콘이 잘리지 않고 충분한 크기로 표시됩니다.
- Login 카드의 외곽선이 배경과 구분됩니다.
- 이메일과 비밀번호 입력 필드가 표시됩니다.
- 로그인 버튼을 누르면 실제 인증 없이 Home으로 이동합니다.
- 회원가입 텍스트를 누르면 Signup 화면으로 이동합니다.
- Signup 화면은 Login과 같은 배경 톤을 유지합니다.
- Signup 화면의 이름, 이메일, 비밀번호, 비밀번호 확인 입력 필드가 표시됩니다.
- Signup 화면의 뒤로가기와 로그인 텍스트는 Login으로 돌아갑니다.
- Signup 화면의 회원가입 버튼은 실제 인증 없이 Home으로 이동합니다.

## Home

- 인사말과 진행 중인 약속 요약이 표시됩니다.
- 이번주 약속 현황에 오늘이 포함된 주간 날짜 7개가 표시됩니다.
- 주간 날짜의 참여 인원과 BEST 표시는 더미 약속 현황 데이터가 있는 경우에만 표시됩니다.
- 내 약속 방 영역에는 데이터 소스 기준 방 1개가 미리보기로 표시됩니다.
- 전체 방 목록은 내 약속 방 옆 전체 보기에서 확인합니다.
- 신규/빈 데이터 상태에서는 진행 중 약속, BEST 날짜, 응답률, 기존 방 목록이 임의로 표시되지 않습니다.
- 빈 방 목록 상태에서는 방 만들기 CTA와 안내 문구가 표시됩니다.
- BEST 표시는 계산 결과 또는 명시된 데이터가 있을 때만 표시됩니다.
- 대표 약속의 BEST 날짜와 가능 인원은 후보 날짜별 응답 가능 인원 계산 결과와 일치합니다.
- 대표 약속의 응답률은 제출된 참여자 응답 수 기준으로 갱신됩니다.
- 마감 D-day는 고정 텍스트가 아니라 방 데이터 기준으로 갱신됩니다.
- 대표 방 상세 버튼 또는 방 row를 누르면 선택한 roomId의 Room Detail로 이동합니다.
- 이번주 약속 현황 옆 전체 보기를 누르면 Calendar 화면으로 이동합니다.
- 내 약속 방 옆 전체 보기를 누르면 전체 방 리스트 화면으로 이동합니다.
- 방 만들기 버튼을 누르면 Create Meetup으로 이동합니다.
- 하단 캘린더 탭을 누르면 Calendar 화면으로 이동합니다.

## All Meetup Rooms

- 전체 방 리스트는 `DummyDataSource.getMyMeetupRooms()`의 모든 방을 표시합니다.
- 각 방 row에는 방 제목, 참여자 수, 마감 D-day, 응답률이 표시됩니다.
- 방 row를 누르면 선택한 roomId의 Room Detail로 이동합니다.
- 새 약속 만들기 버튼을 누르면 Create Meetup으로 이동합니다.
- 뒤로가기를 누르면 Home으로 돌아갑니다.

## Calendar

- 현재 월 기준 실제 달력이 표시됩니다.
- 이전/다음 월 버튼으로 표시 월을 이동할 수 있습니다.
- 일정이 있는 날짜에는 `응답 마감일`, `확정된 약속일` 두 상태의 색상 점만 표시됩니다.
- 하단에는 표시 중인 월에 등록된 약속 일정만 표시됩니다.
- 약속 일정 목록은 `DummyDataSource.getCalendarMeetups()`의 roomId 기반 더미 데이터에서만 생성됩니다.
- 현재 월에 명시된 더미 일정이 없으면 현재 월은 그대로 유지하고 빈 상태를 표시합니다.
- 일정 날짜는 오늘 표시처럼 큰 원형 색상 배경으로 렌더링됩니다.
- 하단 일정 카드를 누르면 해당 일정 roomId의 Room Detail 화면으로 이동합니다.
- 상단 오늘 버튼과 하단 관리 안내 배너는 표시하지 않습니다.

## Create Meetup

- 모임명은 필수입니다.
- 모임명 글자 수가 갱신됩니다.
- 설명 글자 수가 갱신됩니다.
- 모임명을 입력하고 다음 단계로 이동하면 생성한 방이 로컬 방 목록에 등록됩니다.
- 생성한 방의 roomId가 Host Selection과 Invite Members로 전달됩니다.
- 생성한 방은 Chat 화면의 방 목록에서 확인할 수 있습니다.
- 마감일 달력은 현재 월 기준으로 표시되고 이전/다음 월로 이동할 수 있습니다.
- 오늘 이전 마감일은 선택할 수 없습니다.
- 선택한 마감일은 생성한 방 데이터의 마감 날짜로 저장됩니다.
- 마감 시간을 선택할 수 있습니다.
- 인원 수는 최소/최대 범위를 벗어나지 않습니다.
- 공개 범위를 선택할 수 있습니다.
- 알림 토글 상태가 변경됩니다.
- 다음 버튼을 누르면 방 draft가 저장되고 다음 단계로 이동합니다.
- 새 방 생성 시 이전 방에서 선택한 후보 날짜가 새 방에 미리 표시되지 않습니다.

## Host Selection

- 달력이 2025년 5월 고정이 아니라 현재 월 또는 선택 월 기준으로 표시됩니다.
- 달력에서 오늘 이전 날짜는 선택할 수 없습니다.
- 달력에서 후보 날짜를 선택하고 해제할 수 있습니다.
- 선택한 후보 날짜가 상단 후보 날짜 칩으로 표시됩니다.
- 선택한 후보 날짜가 생성한 방 데이터의 후보 날짜로 저장됩니다.
- 후보 날짜 draft는 생성한 방 roomId별로 유지됩니다.
- 선택 개수가 갱신됩니다.
- 최대 선택 개수가 제한됩니다.
- 시간대를 선택하고 해제할 수 있습니다.
- 제외 날짜는 고정 샘플이 아니라 현재 날짜 기준으로 표시되고, 선택 개수가 갱신됩니다.
- 요약 영역이 선택 데이터를 반영합니다.
- 다음 버튼 이동 후 선택한 후보 날짜 데이터가 로컬 draft에 유지됩니다.

## Invite Members

- 생성한 방의 제목, 마감 날짜/시간, 참여 인원, 초대 링크 또는 코드가 표시됩니다.
- 복사 버튼이 초대 문구를 클립보드에 복사합니다.
- 공유 액션에서 Android share sheet가 열립니다.
- 알림 토글 상태가 저장됩니다.
- 방 정보 버튼이 생성된 방 상세로 이동합니다.
- 초대 완료 후 Home 또는 Room Detail로 의도한 대로 이동합니다.

## Room Detail

- 방 제목, 상태, 마감일/마감 시간, 참여 인원, 응답률이 선택한 roomId 기준으로 표시됩니다.
- 시스템 뒤로가기와 제스처 뒤로가기는 AndroidX 뒤로가기 dispatcher를 통해 Home으로 이동합니다.
- 현재 사용자의 응답 상태가 보입니다.
- 응답 CTA가 Response Selection으로 이동합니다.
- 진행 현황 숫자가 참여자 데이터와 일치합니다.
- 확정 일정이 있는 방은 확정 날짜/시간을 표시하고, 확정 일정이 없으면 미정 상태를 표시합니다.
- 후보 날짜별 가능 인원과 가장 유력한 날짜가 roomId별 응답 더미 데이터 계산 결과로 표시됩니다.
- 시간 선호도 막대가 roomId별 응답 더미 데이터 계산 결과로 표시됩니다.
- 생성 방처럼 응답 더미 데이터가 없는 방에서도 하드코딩된 후보 날짜/응답률이 표시되지 않습니다.
- 참여자 목록은 이모지 아바타에 의존하지 않습니다.
- 참여자 섹션의 전체 보기를 누르면 참여자 전체 목록 화면으로 이동합니다.
- 참여자 전체 목록은 원형 프로필 placeholder와 이름, 응답 상태를 세로 리스트로 표시합니다.
- 리마인더 액션은 구현되어 있거나 stub임이 명확합니다.
- 공유 액션에서 Android share sheet가 열립니다.

## Participant Response Selection

- 달력이 2025년 5월 고정 샘플이 아니라 방장이 고른 후보 날짜의 월을 기준으로 표시됩니다.
- 캘린더에 방장 후보 날짜만 선택 가능 상태로 표시되고, 나머지 날짜는 비활성화됩니다.
- 제외 날짜 칩은 고정 샘플이 아니라 선택한 방의 후보 날짜를 기준으로 표시됩니다.
- 날짜를 선택하면 선택 날짜 영역이 갱신됩니다.
- 선택 날짜를 제거하면 캘린더 상태도 갱신됩니다.
- 시간대는 복수 선택할 수 있습니다.
- 제외 날짜 개수가 갱신됩니다.
- 선택 완료 후 같은 roomId의 Room Detail로 돌아갑니다.
- 제출 결과의 로컬 저장과 기존 응답 복원은 다음 저장소 연동 단계에서 검증합니다.

## Notifications

- Home 상단 알림 버튼을 누르면 알림 화면으로 이동합니다.
- 오늘, 이번 주, 이전 섹션 제목이 순서대로 표시됩니다.
- 응답 완료, 마감 임박, 일정 확정, 초대, 댓글 알림이 로컬 더미 데이터 기준으로 표시됩니다.
- 알림 항목에는 제목, 방 이름, 선택 보조 문구, 발생 시각이 표시됩니다.
- 뒤로가기를 누르면 Home으로 돌아갑니다.
- 하단 내비게이션의 알림 탭은 현재 알림 화면과 연결하지 않습니다.
- 빈 상태, 모두 읽음, 읽음/안읽음 저장은 아직 구현하지 않습니다.

## Chat

- Home 하단 방 채팅 탭을 누르면 Chat 화면으로 이동합니다.
- Chat 화면은 roomId 기반 약속 방 더미 데이터 기준으로 방 목록을 표시합니다.
- 새 일정 잡기 방을 생성한 뒤 Chat 화면으로 돌아오면 생성한 방도 표시됩니다.
- 방 목록에는 방 제목, 참여자 수, 마감 날짜/시간, 응답률이 표시됩니다.
- 생성 방처럼 메시지가 없는 방은 방 목록 미리보기와 Chat Detail에서 빈 채팅 상태를 표시합니다.
- 참여 중인 방 탭을 누르면 기존 방 목록이 표시됩니다.
- 종료된 방 탭을 누르면 현재 종료된 방 빈 상태가 표시됩니다.
- 종료된 방에서 참여 중인 방으로 다시 전환할 수 있습니다.
- 방 row를 누르면 선택한 roomId의 Chat Detail 화면으로 이동합니다.
- Chat Detail 화면은 더미 메시지 목록을 표시합니다.
- 각 메시지는 발신자 이름 첫 글자 원형 배지를 표시합니다.
- 발신자 이름은 메시지 버블 안이 아니라 버블 위에 표시됩니다.
- 상단 공지 카드는 같은 roomId의 방 데이터 기준으로 참여자 수, 응답률, 마감 날짜/시간을 표시합니다.
- 더미 메시지는 음식과 장소 후보를 정하는 대화로 표시됩니다.
- 입력창에 텍스트를 입력할 수 있습니다.
- 전송 버튼을 누르면 입력한 텍스트가 내 메시지로 화면에 추가됩니다.
- 첨부파일, 이모티콘 입력, 좋아요 UI는 표시되지 않습니다.
- Chat 화면과 Chat Detail 화면은 주요 UI 의미를 이모지에 의존하지 않습니다.

## My Info

- 내 정보 탭을 누르면 내 정보 화면으로 이동합니다.
- 로컬/게스트 사용자 이름과 프로필 placeholder가 표시됩니다.
- 실제 인증이 없으면 동기화된 계정처럼 보이지 않습니다.
- 로그아웃 또는 로컬 데이터 초기화가 있다면 확인 과정을 거칩니다.

## Backend-ready 확인

- Activity가 Retrofit을 직접 호출하지 않습니다.
- Repository interface와 API Repository 교체 구조는 다음 저장소 계층 정리 단계에서 추가합니다.
- 달력, 통계, 참여자 상태는 Activity 하드코딩이 아니라 모델/로컬 데이터 소스/계산기에서 나옵니다.
- 문서와 실제 동작이 일치합니다.
- 빌드가 통과합니다.
