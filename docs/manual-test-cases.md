# 수동 테스트 케이스

테스트는 샘플 방과 새로 만든 방을 구분해 진행합니다. 생성 데이터는 프로세스가 종료되면 초기화됩니다. 아래 항목은 점검 목록이며 수동 검증 완료 기록은 아닙니다.

## 실행과 내비게이션

- [ ] Splash에서 약 2초 후 Login으로 이동합니다.
- [ ] Login은 인증 입력란을 비활성화하고 게스트 시작을 제공합니다.
- [ ] Signup은 회원가입 미리보기이며 게스트 체험으로 Home에 진입합니다.
- [ ] 하단 홈·캘린더·방 채팅·내 정보 탭이 해당 화면을 엽니다.
- [ ] 홈 상단 알림 버튼이 알림 목록을 엽니다.
- [ ] 게스트 진입과 로그아웃 후 뒤로가기에 이전 시작·홈 화면이 중복되지 않습니다.
- [ ] 로그아웃 후에도 같은 프로세스의 메모리 데이터는 유지됩니다.

## 방 생성과 수정

- [ ] 제목 공백, 30자 초과, 설명 100자 초과를 제한합니다.
- [ ] 정원은 2~20명이며 새 방의 실제 인원은 방장 1명입니다.
- [ ] 마감 날짜·시간은 현재 이후만 허용합니다.
- [ ] 다음 단계에서 생성한 방 ID가 후보 설정과 초대 화면으로 이어집니다.
- [ ] 같은 제목으로 두 방을 만들어도 후보·응답·채팅이 섞이지 않습니다.
- [ ] 후보 설정에서 뒤로 돌아와 정보를 수정하면 ID가 유지되고 방이 늘어나지 않습니다.
- [ ] 응답 없는 작성 중 방은 마감이 지나도 새 마감일로 수정할 수 있습니다.
- [ ] 마감일을 바꾸면 그 날짜와 이전 후보가 제거됩니다.
- [ ] 작성 중 회전하면 정원과 마감 날짜·시간이 유지됩니다.

## 방장 후보 설정

- [ ] 현재 월에서 이전·다음 월로 이동할 수 있습니다.
- [ ] 마감일 다음날부터 후보를 1~10개 선택합니다.
- [ ] 후보와 제외 날짜가 겹치면 후보에서 제거됩니다.
- [ ] 허용 시간대는 하나 이상 필요하며 상관없음은 모든 기본 시간대를 허용합니다.
- [ ] 선택 칩, 개수와 요약이 입력값과 일치합니다.
- [ ] 뒤로 나갔다 다시 진입하거나 회전해도 작성 중 선택이 복원됩니다.
- [ ] 다음 단계 완료 전에는 작성 중 선택이 응답 후보로 공개되지 않습니다.
- [ ] 응답 제출 후 후보 날짜와 허용 시간 변경을 제한합니다.

## 참여자와 응답

- [ ] 참여자 전체 보기에서 이름과 제출 상태를 확인합니다.
- [ ] 이름 공백·20자 초과·중복과 정원 초과를 제한합니다.
- [ ] 참여자를 누르면 해당 방과 이름의 응답 화면이 열립니다.
- [ ] 해당 방 후보만 달력에서 선택 가능하며 허용 시간대만 표시됩니다.
- [ ] 날짜 선택과 제외 선택, 상관없음과 개별 시간 선택은 상호 배제됩니다.
- [ ] 후보 10개가 모두 제외 날짜 영역에 표시됩니다.
- [ ] 가능한 날짜가 있으면 시간대 없이 제출할 수 없습니다.
- [ ] 모든 후보를 제외하면 시간대 없이 참여 불가로 제출합니다.
- [ ] 제출 후 같은 방 상세에서 응답률과 추천을 갱신합니다.
- [ ] 재진입·회전 시 선택을 복원하고 수정 제출은 이전 응답을 교체합니다.
- [ ] 마감 이후와 확정 이후에는 추가 버튼과 응답 입력을 비활성화합니다.

## 계산과 일정 확정

- [ ] 응답 0건은 집계 대기이며 추천을 표시하지 않습니다.
- [ ] 전원 참여 불가 응답은 제출률에 반영하지만 가능 인원에는 포함하지 않습니다.
- [ ] 해당 날짜에 불가능한 참여자의 시간 표는 그 날짜 집계에 포함하지 않습니다.
- [ ] 상관없음은 방장이 허용한 각 시간대에 한 표씩 반영합니다.
- [ ] 날짜 인원이 4명이지만 시간대가 2명씩 나뉜 후보보다 3명이 같은 시간에 가능한 후보를 우선합니다.
- [ ] 조합 인원 동점은 날짜 인원, 날짜, 시간 순으로 정렬합니다.
- [ ] 홈 추천과 상세 강조, 확정 목록의 첫 후보가 일치합니다.
- [ ] 과거 날짜와 시작 시간이 지난 조합은 확정할 수 없습니다.
- [ ] 미응답자가 있으면 확정 확인 문구에 표시합니다.
- [ ] 방장만 확정할 수 있고 확정 후 수정이 차단됩니다.
- [ ] 홈·상세·캘린더가 같은 확정 일정과 실제 가능 인원을 표시합니다.

## 목록·초대·캘린더

- [ ] 홈 방 미리보기는 최대 5개, 전체 보기는 모든 방을 표시합니다.
- [ ] 주간 날짜 7개와 날짜별 가능 인원이 실제 응답·확정 상태에 맞습니다.
- [ ] 방 목록과 일정 카드는 선택한 방 ID의 상세를 엽니다.
- [ ] 빈 방·일정 영역은 빈 상태를 표시합니다.
- [ ] 월 달력은 마감일과 확정 약속일을 구분하고 같은 월의 일정만 목록에 표시합니다.
- [ ] 초대 화면의 참여 인원과 응답 수는 방 데이터와 일치하며 재진입 시 갱신됩니다.
- [ ] 초대 문구 복사는 클립보드, 공유는 Android 공유 시트를 사용합니다.
- [ ] 다른 기기에서 링크로 참여하는 기능이 준비 중임을 안내합니다.
- [ ] 참여 알림 토글이 방 설정에 반영됩니다.

## 채팅·알림·내 정보

- [ ] 채팅 목록은 새 방과 샘플 방, 마지막 메시지 미리보기를 표시합니다.
- [ ] 메시지가 없는 방은 빈 채팅 상태를 표시합니다.
- [ ] 보낸 메시지는 해당 방에만 추가되고 같은 프로세스에서 재진입 시 유지됩니다.
- [ ] 채팅 공지의 인원·응답률·마감이 해당 방과 일치합니다.
- [ ] 종료된 방 탭은 빈 목록을 표시합니다.
- [ ] 참여 알림이 켜진 방의 참여 이벤트, 응답과 확정 이벤트가 알림에 반영됩니다.
- [ ] 로컬 이벤트와 샘플 상태 요약을 오늘·샘플 섹션으로 구분합니다.
- [ ] 내 정보의 방·일정 현황이 갱신되고 미지원 메뉴는 준비 중을 안내합니다.

## 화면과 예외

- [ ] 작은 화면과 글자 확대에서 폼·달력·완료 버튼을 확인할 수 있습니다.
- [ ] 키보드가 열린 상태에서도 입력창과 전송·완료 동작에 접근할 수 있습니다.
- [ ] 긴 제목·이름·메시지가 주요 정보를 가리지 않습니다.
- [ ] 선택·비활성·오류 상태가 색상 외의 표시로도 구분됩니다.
- [ ] 달력·칩·아이콘 터치 영역과 접근성 설명을 확인합니다.
- [ ] 시스템 테마와 관계없이 밝은 테마가 유지되고 여러 화면 크기에서 잘림·겹침·대비가 정상입니다.
- [ ] 잘못된 방 ID는 다른 샘플 방 대신 안내 후 화면을 닫습니다.
- [ ] 프로세스를 종료하고 다시 시작하면 생성 데이터가 사라지고 샘플 상태로 시작합니다.

## 문자열 리소스

- [ ] 인원·정원·응답률·선택 개수의 숫자와 단위가 맞습니다.
- [ ] 날짜·시간 표시와 초대 문구의 줄바꿈을 확인합니다.
- [ ] 추천 카드와 확정 안내의 가능 인원·미응답 인원이 맞습니다.
- [ ] 선택 기호와 접근성 설명이 선택 상태와 일치합니다.
- [ ] lint의 `HardcodedText`, `SetTextI18n`, `StringFormatMatches` 항목을 확인합니다.

## 자동 테스트

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

| 테스트 | 범위 |
| --- | --- |
| `LocalMeetupFlowTest` | 방 구분·수정, 입력 검증, 응답 교체, 계산 순위, 확정 제한, 채팅 격리, 사용자 통계 |
| `LocalMeetupFlowInstrumentedTest` | 응답→확정, 후보 10개와 회전 복원, 참여자 추가, 전원 참여 불가, 작성 중 복원, 마감 상태, 생성 흐름 뒤로가기, 키보드 채팅 전송, 실제 사용자 통계 |

자동 테스트는 기기 크기별 시각 점검을 대체하지 않습니다. 검증 기록에는 코드 버전, 기기·Android 버전, 결과와 실패 항목을 남깁니다. 보고서는 `app/build/reports` 아래에 생성됩니다.
