# 수동 테스트 케이스

앱이 목업에서 서버-ready 로컬 동작으로 이동하는 동안 이 문서를 계속 업데이트합니다.

## 공통

- 앱이 crash 없이 실행됩니다.
- Splash에서 Login 또는 Home으로 이동합니다.
- 뒤로가기 시 저장된 데이터가 예기치 않게 사라지지 않습니다.
- 주요 UI 의미가 이모지에 의존하지 않습니다.
- 주요 화면이 현재 디자인 방향과 맞습니다.

## Home

- 인사말과 진행 중인 약속 요약이 표시됩니다.
- 가능한 날짜가 데이터 소스 기준으로 표시됩니다.
- 내 약속 방 목록이 데이터 소스 기준으로 표시됩니다.
- 신규/빈 데이터 상태에서는 진행 중 약속, BEST 날짜, 응답률, 기존 방 목록이 임의로 표시되지 않습니다.
- 빈 방 목록 상태에서는 방 만들기 CTA와 안내 문구가 표시됩니다.
- BEST 표시는 계산 결과 또는 명시된 데이터가 있을 때만 표시됩니다.
- 방 row를 누르면 올바른 Room Detail로 이동합니다.
- 방 만들기 버튼을 누르면 Create Meetup으로 이동합니다.

## Create Meetup

- 모임명은 필수입니다.
- 모임명 글자 수가 갱신됩니다.
- 설명 글자 수가 갱신됩니다.
- 마감일을 선택할 수 있습니다.
- 마감 시간을 선택할 수 있습니다.
- 인원 수는 최소/최대 범위를 벗어나지 않습니다.
- 공개 범위를 선택할 수 있습니다.
- 알림 토글 상태가 변경됩니다.
- 다음 버튼을 누르면 방 draft가 저장되고 다음 단계로 이동합니다.

## Host Selection

- 후보 날짜를 선택하고 해제할 수 있습니다.
- 선택 개수가 갱신됩니다.
- 최대 선택 개수가 제한됩니다.
- 시간대를 선택하고 해제할 수 있습니다.
- 제외 날짜가 표시되는 경우 선택 개수가 갱신됩니다.
- 요약 영역이 선택 데이터를 반영합니다.
- 다음 버튼 이동 후 선택 데이터가 유지됩니다.

## Invite Members

- 초대 링크 또는 코드가 표시됩니다.
- 복사 버튼이 초대 문구를 클립보드에 복사합니다.
- 공유 액션에서 Android share sheet가 열립니다.
- 알림 토글 상태가 저장됩니다.
- 방 정보 버튼이 생성된 방 상세로 이동합니다.
- 초대 완료 후 Home 또는 Room Detail로 의도한 대로 이동합니다.

## Room Detail

- 방 제목, 마감, 인원 범위, 상태가 올바르게 표시됩니다.
- 현재 사용자의 응답 상태가 보입니다.
- 응답 CTA가 Response Selection으로 이동합니다.
- 진행 현황 숫자가 참여자 데이터와 일치합니다.
- 가장 유력한 날짜가 일정 계산 결과로 표시됩니다.
- 시간 선호도 막대가 일정 계산 결과로 표시됩니다.
- 참여자 목록은 이모지 아바타에 의존하지 않습니다.
- 리마인더 액션은 구현되어 있거나 stub임이 명확합니다.
- 공유 액션에서 Android share sheet가 열립니다.

## Participant Response Selection

- 캘린더에 선택 가능/불가 날짜가 표시됩니다.
- 날짜를 선택하면 선택 날짜 영역이 갱신됩니다.
- 선택 날짜를 제거하면 캘린더 상태도 갱신됩니다.
- 시간대는 복수 선택할 수 있습니다.
- 제외 날짜 개수가 갱신됩니다.
- 제출 시 응답이 로컬에 저장됩니다.
- 기존 응답을 수정할 때 이전 선택이 복원됩니다.

## Place Input

- 가능한 장소를 입력할 수 있습니다.
- 희망 장소를 입력할 수 있습니다.
- 빈 장소 입력이 처리됩니다.
- 중복/유사 장소 처리 방식이 문서화되어 있습니다.
- 제출한 장소가 결과 점수에 반영됩니다.

## Result And Confirmation

- 전원 교집합 날짜가 우선 표시됩니다.
- 날짜 점수는 가능한 날짜 + 희망 날짜 가중치를 사용합니다.
- 장소 점수는 가능한 장소 + 희망 장소 가중치를 사용합니다.
- 방장이 최종 일정을 확정할 수 있습니다.
- 확정 일정이 Home과 Room Detail에 반영됩니다.
- 확정 일정 공유에서 Android share sheet가 열립니다.
- 캘린더 추가가 구현되어 있거나 pending으로 명확하게 문서화되어 있습니다.

## Backend-ready 확인

- Activity가 Retrofit을 직접 호출하지 않습니다.
- API 구현 전 Repository interface가 존재합니다.
- Local Repository를 API Repository로 교체할 수 있습니다.
- 문서와 실제 동작이 일치합니다.
- 빌드가 통과합니다.
