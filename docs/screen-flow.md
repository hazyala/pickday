# 화면 흐름

## 주요 경로

- 앱 진입: `SplashActivity` → `LoginActivity` → 게스트 시작 → `HomeActivity`
- 방 생성: `HomeActivity` → `CreateMeetupActivity` → `SelectionActivity` → `InviteMembersActivity`
- 응답과 확정: `RoomDetailActivity` → `ParticipantListActivity` → `ResponseSelectionActivity` → 방 상세 → 일정 확정
- 일정 확인: 홈 → `CalendarActivity` → 선택한 방 상세
- 채팅: 하단 방 채팅 → `ChatActivity` → `ChatDetailActivity`
- 알림: 홈 상단 알림 → `NotificationActivity`
- 내 정보: 하단 내 정보 → `MyPageActivity`

## 화면별 동작

| 화면 | 표시와 동작 |
| --- | --- |
| Splash | 브랜드 화면을 약 2초 표시한 뒤 Login으로 이동 |
| Login | 비활성 인증 입력란과 게스트 시작 버튼, Signup 이동 링크 |
| Signup | 회원가입 미리보기, 비활성 입력란, 게스트 데모 체험과 Login 복귀 |
| Home | 대표 방, 주간 현황, 최대 5개 방 미리보기, 생성·알림·전체 보기 진입 |
| All Meetup Rooms | 샘플과 생성 방 전체 목록, 선택한 방 상세 이동 |
| Calendar | 현재 월과 월 이동, 응답 마감일·확정 약속일 표시, 월별 일정 목록 |
| Create Meetup | 제목·설명·정원·마감 입력, 검증 후 같은 방의 후보 선택으로 이동 |
| Selection | 방장 후보 날짜·시간·제외 선택, 작성 중 상태 보관, 다음 단계에서 후보 반영 |
| Invite Members | 방 정보, 실제 참여·응답 수, 초대 문구 복사·공유, 참여 알림 토글 |
| Room Detail | 방별 현황과 추천, 내 응답, 참여자 보기, 일정 확정, 공유 |
| Participant List | 이름과 응답 상태, 로컬 참여자 추가, 각 참여자의 응답 입력 |
| Response Selection | 해당 방 후보와 허용 시간만 선택, 제외·상관없음 처리, 제출·수정 |
| Notifications | 실행 중 로컬 이벤트는 오늘 섹션, 기본 방 상태는 샘플 섹션 |
| Chat | 방별 마지막 메시지 미리보기, 채팅 상세 이동, 종료된 방 탭은 빈 목록 |
| Chat Detail | 같은 방의 메시지와 공지, 메모리 메시지 전송 |
| My Page | 게스트 정보와 방 현황, 전체 방·캘린더 이동, 서비스 소개, 로그아웃 |
| My Page Action | 프로필·설정 등 미지원 메뉴의 준비 중 안내와 서비스 소개 |

## 화면 간 데이터

Home, 전체 방 목록, Calendar는 선택한 방 ID를 `RoomDetailActivity.EXTRA_ROOM_ID`에 담습니다. 방 생성은 같은 ID를 Selection과 Invite로 전달합니다. 참여자 응답은 방 ID와 참여자 이름을 사용하며, Chat은 `ChatDetailActivity.EXTRA_ROOM_ID`를 전달합니다.

화면에 다시 진입하면 메모리 데이터로 현황을 갱신합니다. 후보 설정에서 뒤로 돌아가 방 정보를 수정해도 방 ID를 유지합니다. 작성 중 후보와 제출 응답은 별도로 관리합니다.

## 입력과 상태 처리

- 방 생성 검증 실패는 안내 문구를 표시하고 입력 화면에 머뭅니다.
- 방장 후보는 응답 마감일 다음날부터 선택할 수 있습니다.
- 후보가 없는 새 방의 상세에서는 방장 후보 설정으로 이동합니다.
- 응답 선택은 해당 방의 후보 날짜만 활성화합니다. 날짜 선택과 제외 선택은 상호 배제됩니다.
- 모든 후보를 제외한 참여자는 참여 불가 응답을 제출할 수 있습니다.
- 응답 수집이 마감되면 참여자 추가와 응답 입력을 비활성화합니다.
- 일정 확정 목록은 가능한 조합과 인원을 표시합니다. 미응답자가 있으면 확인 문구에 포함합니다.
- 확정된 방은 최종 날짜·시간을 표시하고 응답·참여자 수정을 막습니다.
- 잘못된 방 ID는 안내 후 화면을 닫습니다.
- 방이나 일정, 메시지가 없는 영역은 빈 상태를 표시합니다.

## 내비게이션

방 상세의 뒤로가기는 Home으로 이동합니다. 방장 후보와 초대 화면에서는 이전 단계로 돌아갈 수 있습니다. 게스트 시작과 로그아웃은 태스크를 정리해 시작 화면과 홈이 중복해서 쌓이지 않게 합니다.

로그아웃은 Login으로 이동하는 기능입니다. 계정 세션이나 저장 데이터 삭제는 수행하지 않습니다.

## 미지원 기능

이메일·소셜 인증, 실제 계정 생성, 다른 기기의 초대 참여, 네트워크 채팅, 푸시, 알림 읽음 처리, 프로필 편집과 설정 저장은 제공하지 않습니다. 초대 화면의 공유 버튼은 Android 공유 시트를 사용하며 Kakao SDK는 연결하지 않습니다. 공개 범위 제어와 방 종료 정책도 구현되어 있지 않습니다.
