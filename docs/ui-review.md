# UI·사용성 점검 결과

점검일: 2026-10-07

## 실행 환경과 범위

- Medium Phone 에뮬레이터, Android 17 / API 37
- 기본 화면: 1080×2400px, 420dpi, 글자 크기 100%
- 작은 화면: 720×1280px, 320dpi, 360×640dp, 글자 크기 130%
- 디버그 APK를 설치해 화면을 직접 누르고 스크롤하며 확인

기본 화면에서 홈, 생성, 후보 설정, 초대, 상세, 응답, 확정 다이얼로그, 채팅과 내 정보를 확인했습니다. 작은 화면에서는 홈, 생성·마감 달력, 후보 설정, 30자 영문 제목의 초대·상세, 응답, 내 정보와 캘린더를 확인했습니다. 실제 기기, 가로 화면, TalkBack 전체 흐름은 확인하지 않았습니다.

## 수정 내용과 확인 결과

| 항목 | 수정 | 확인 결과 |
| --- | --- | --- |
| 키보드 | 공통 `PickDayActivity`에서 IME·시스템 바·화면 잘림 영역 여백 처리 | 키보드를 연 채 채팅 전송과 생성의 다음 버튼 실행 |
| 작은 화면·글꼴 확대 | 내용 높이와 줄바꿈·스크롤 적용, 마감 날짜·시간 세로 배치 | 홈 제목·일정 시간, 마감 시간과 달력 숫자를 읽을 수 있음 |
| 내 정보 통계 | 현재 사용자 기준 진행·응답·확정·전체 방 수 집계, 2열 카드 | 기본 데이터 1·3·2·3개 표시, 생성·응답·확정 전후 자동 테스트 통과 |
| 공통 달력 | 날짜 행 48dp, 월 이동 버튼 48dp, 날짜 접근성 설명 | 360dp 화면에서 날짜 높이 96px 확인, 월 이동·선택 정상 |
| 긴 제목·정보 겹침 | 캐릭터와 제목·메타 정보 분리, 초대 카드 세로 구성 | 30자 영문 제목이 줄바꿈되며 상태·마감·인원·버튼 유지 |
| 시간 선택 | 허용 시간만 2열의 연속된 행으로 배치, 내용에 맞는 높이 | 오후만 허용할 때 오후·상관없음이 같은 행에 표시 |
| 하단 탭 | 내 정보의 채팅 이름·아이콘·이동 대상 통일 | 홈·캘린더·채팅·내 정보에서 방 채팅으로 표시 |
| 상태 안내 | 홈 확정 일정 라벨, 마감·확정 참여자 안내 구분 | 확정 상태에서 입력 가능하다는 안내가 남지 않음 |
| 미지원 메뉴 | 프로필·푸시·테마 준비 중 표시, 캘린더 날짜순 라벨 | 실제 지원 범위에 맞는 안내 표시 |
| 뒤로가기 | 생성·후보 화면의 버튼을 스크롤 밖에 고정 | 후보·초대에서 돌아가 제목을 수정해도 방이 중복 생성되지 않음 |

달력 날짜는 화면 너비를 7열로 나눕니다. 작은 화면에서는 각 날짜의 너비가 48dp보다 작을 수 있으며, 높이는 48dp를 확보합니다.

## 기능 흐름

방 생성 → 후보 두 개와 오후 시간 설정 → 초대 → 본인 응답 제출 → 응답률 100% 확인 → 후보 선택 → 최종 확정을 직접 진행했습니다. 채팅에서는 키보드를 연 채 메시지를 입력하고 전송했습니다. 후보 10개·응답 복원·전부 제외·마감 제한·통계 변경은 자동 화면 테스트로 확인합니다.

## 테마

시스템 다크 설정에서도 홈이 밝은 배경과 읽을 수 있는 상태 표시를 유지하는 것을 확인했습니다. 앱은 밝은 테마를 사용합니다. `values`와 `values-night` 모두 라이트 테마로 지정해 시스템 설정으로 배경과 입력 색상 일부만 바뀌는 혼합을 방지합니다. 별도의 다크 테마와 테마 설정 기능은 제공하지 않습니다.

## 검증

- 디버그 빌드 성공
- 단위 테스트 25개 통과: 기능 테스트 24개, 기본 템플릿 테스트 1개
- 기기 테스트 10개 통과: 기능 화면 테스트 9개, 기본 템플릿 테스트 1개
- lint 오류 0개, 경고 150개. 접근성 설명·미사용 리소스·이미지 위치·자동 완성 등 경고는 남아 있음
- XML 파싱과 `git diff --check` 통과

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:lintDebug
```

## 평가와 남은 범위

확인한 조건에서 핵심 기능을 막는 UI 문제는 재현되지 않았습니다. 한 기기의 메모리 데이터를 이용한 약속 조율 앱으로 포트폴리오에 시연할 수 있는 수준입니다.

전체 화면과 모든 기기에서 우수하다고 평가하려면 실제 기기의 터치·키보드, Android 버전별 배치, 가로 화면, TalkBack과 색 대비 점검이 더 필요합니다. lint의 접근성·리소스 경고 정리도 남아 있습니다. 영구 저장과 서버 연동은 현재 구현 범위에 포함하지 않습니다.
